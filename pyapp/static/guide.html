Python app + Crawl4AI in Docker Compose

Shelf Notes is the Python service. Crawl4AI is a second container. Compose starts both. The shelf calls Crawl4AI’s /md endpoint for one URL at a time.

Start both

export CRAWL4AI_API_TOKEN="$(openssl rand -hex 32)"
docker compose up -d

Shelf is on port 8080. Crawl4AI is on 11235. The token is shared so the crawler accepts the shelf’s requests.

What Crawl URL does

The button posts the URL to this app. This app posts it to CRAWL4AI_URL/md with Authorization: Bearer. The markdown comes back, prices and place are extracted, and you save the card into SQLite.

Without Docker

pip install -r requirements.txt
export CRAWL4AI_URL=http://127.0.0.1:11235
export CRAWL4AI_API_TOKEN=your-token
uvicorn app:app --app-dir pyapp --host 0.0.0.0 --port 8080

If Crawl4AI is down, paste page text and use Extract. Import still accepts {"url","markdown"} or a list of those objects.

Data

SQLite lives in the shelf-data volume at /data/shelf.db. It is not wiped when the container restarts.
